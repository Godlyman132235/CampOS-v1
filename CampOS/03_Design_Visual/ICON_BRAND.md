# CampOS v1 — Icon and Brand

## Current Status

v1 is using a semi-prototype visual identity. The real, finalized brand 
is a v2 concern. Do not invest significant time in logo design before 
the prototype validates.

---

## v1 Wordmark

**The CampOS brand mark for v1 is the word "CampOS" typeset in 
Playfair Display (serif), bold weight, in `--color-text-primary`.**

Optional treatment:
- The "OS" can be rendered in `--color-purple-strong` to create a subtle 
  two-tone wordmark (CampOS where "Camp" is off-white and "OS" is purple)
- No icon, no logomark, no symbol — wordmark only for v1

Where it appears:
- Top-left of the Dashboard navigation bar
- Browser tab title
- GitHub Pages URL subdomain (camposlearning, or similar)

## Brand Direction (v2 Target — Not v1)

These are placeholder notes for future brand work. Do not act on 
these in v1.

**Name:** CampOS — the "Camp" suggests a learning environment, a place 
to develop skills. The "OS" grounds it in software and operating systems — 
technical, serious.

**Desired brand feelings:** Serious, capable, modern, trustworthy, 
forward-looking. Not playful, not soft, not corporate.

**Potential logo directions to explore in v2:**
- Abstract mark suggesting a terminal cursor, a structural grid, or 
  a code bracket — technical without being literal
- Wordmark only with careful typographic treatment
- Monogram (C) with geometric structure

**Colours in v2 brand identity:** Should derive from the dark purple + 
dark blue palette already established. No new colours introduced.
