# CampOS — Learning Objectives

This file maps what CampOS teaches to specific scenarios and theory
pieces. It is the connection layer between content and outcomes.

The older “eight concepts / Always Check the Full Output / code review”
map is superseded. V1 teaches the five pillars, not code reading.

---

## The Core Transformation (What The Prototype Must Prove)

A user who completes all 8 scenarios should move from this state:

BEFORE: Uses AI agents to generate software and accepts the output
because it looks right or because the AI says it is correct. Has no
reliable way to check whether the AI did what was intended. Feels
helpless when something breaks. Prompting is the only move they have.

TO this state:

AFTER: Can give persistent context, check whether agent output matches
what they asked, choose tools on purpose, keep a project the agent can
reuse, and write down lessons — without reading code.

## Theory 1 — Orientation

Status: Active. First theory piece. No scenario attached.

What it does:
Names vibe coding vs agentic engineering and shows the five pillars
at a glance. It is not Context Engineering.

Unlocks: Theory 2 only.

---

## Theory 2 — Context Engineering (Pillar 1)

Status: Active.

What it means in plain English:
The quality of what an AI agent produces is shaped by the quality of
the context you give it. Useful context names intent, constraints, and
what done looks like, and it lives in a file the agent can reuse.

Linked scenario: Scenario 1 — The Vague Request
Unlocks: Scenario 1 after a passing check (3 of 4).

---

## Theory 3 — Agentic Validation (Pillar 2)

Status: Planned.

What it means in plain English:
An agent saying “done” is not evidence. The learner proves the work
matches what was asked.

Linked scenario: Scenario 2 (one pillar).

## Theory 4 — Agentic Tooling (Pillar 3)

## How The Loop Works After Theory 1

1. Read the theory piece (500–700 words).
2. Applied MCQ. Pass is 3 of 4.
3. Linked scenario unlocks.
4. Workspace: review scripted output, execute the pillar.
5. A–E grade plus written feedback. Return to Dashboard.
6. Repeat.

Theory 1 is the single exception: passing unlocks Theory 2, not a scenario.
