# CampOS — Source of Truth

Read this file first, every session. If another file disagrees with this one, this file wins until the user logs a new decision in DECISIONS_LOG.md.

## Audience

V1 is for non-programmers only (primarily males 16–24 who vibe-code and want control). V2 skill-tier names are out of scope.

## Five pillars (teaching order)

CampOS’s own map, adapted from John Kim — not an industry standard.

1. Context Engineering
2. Agentic Validation
3. Agentic Tooling
4. Agentic Codebase (not taught in V1)
5. Compound Engineering

V1 teaches Context Engineering in depth via Theory 2 and Scenario 1. The other four pillars are named in the orientation but Agentic Codebase is NOT taught as its own theory-and-scenario in V1 — it is a V2 concern. (Later scenarios may cover more pillars if the scenario count grows.)

## Curriculum and loop

Nine theory pieces. Theory 1 is orientation and unlocks Theory 2 only (no scenario). Theories 2–7 cover the five pillars. Theories 8–9 pair with capstone scenarios.
After Theory 1: theory → applied MCQ (pass is 3 of 4) → linked scenario unlocks → Workspace → A–E grade plus written feedback → Dashboard.
Scenarios 1–6 exercise one pillar each. Scenarios 7–8 use all five pillars.
One continuous project: founder launch / waitlist page.

## Grading

A–E measures how effectively and efficiently the learner completed the checklist. No single required answer. No points, badges, streaks, or ranking against other users. Feedback may name issues found (e.g. 3 of 4 invented claims). Score-style “you got X/Y right” is banned.

## Workspace and agent (V1)

No code viewer and the agent is fully scripted. No live model. No API. No bring-your-own key.
Direction is a small set of defined instruction choices, each with a scripted outcome. No free-text prompt box.
Code reading is a V2 concern.

## Product frame

Dashboard, Theory, and Workspace are the three areas.
V1 is vanilla HTML/CSS/JS. Frameworks may be reconsidered at V2.
Minimal backend exists and will expand; it is not a user-facing product yet.
Tester email is collected once, upfront, only for demo contact (reminders, feedback). No accounts, no other individual data, no user-to-user features, no theme switcher.
Three fonts (Playfair Display, Inter, JetBrains Mono), bundled locally.
Theory pieces are 500–700 words.
