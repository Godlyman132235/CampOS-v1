# CampOS v1 — Feedback Log

Raw feedback from real testers. Logged verbatim as received. 
No editing, no paraphrasing, no cherry-picking.

---

## Logging Rules

1. **Log verbatim.** Copy the exact words. Do not paraphrase.
2. **Note the source.** Which channel did it come from?
3. **Note whether it was prompted or unprompted.** Prompted = you asked 
   "what did you think?" Unprompted = they said it without being asked.
4. **Note the tester profile if known.** Coding knowledge level. 
   How they found CampOS.
5. **Do not filter.** Log negative feedback with the same care as positive.

---

## Feedback Channels

| Channel | How To Share |
|---------|-------------|
| Social media reply | Screenshot + paste text |
| Social media DM | Paste text |
| Email | Paste text |
| Verbal (in person) | Summarise and note "verbal — not verbatim" |
